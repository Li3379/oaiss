# Plan 09-01: Fabric 网络搭建 + Gateway SDK 集成

**Phase:** 9 (区块链真实对接)
**Requirement:** REQ-05 (Hyperledger Fabric 真实对接)
**Depends on:** Phase 6 (v1.0 complete)
**Estimated tasks:** 8

## Goal

搭建 Hyperledger Fabric 测试网络（Docker Compose），集成 Fabric Gateway SDK Java 客户端，实现 Spring Boot 与 Fabric peer 的 gRPC 连接，为后续链码部署和 BlockchainService 替换奠定基础。

## Success Criteria

1. `docker-compose up` 启动 Fabric 网络（peer + orderer + CouchDB + CA）且所有容器健康
2. Fabric 通道 `mychannel` 创建成功，peer 已加入通道
3. Spring Boot 应用可通过 `fabric.enabled=true` profile 连接到 Fabric peer
4. `FabricGatewayConfig` 创建 Gateway bean，`FabricBlockchainService` 可调用 `contract.submitTransaction()` 和 `contract.evaluateTransaction()`
5. `fabric.enabled=false`（默认）时，MockBlockchainService 继续正常工作（API 行为不变）
6. 后端编译通过，单元测试通过

### Task 4: 创建 FabricGatewayConfig 配置类

**Files:**
- `oaiss-chain-backend/src/main/java/com/oaiss/chain/config/FabricGatewayConfig.java` (NEW)

创建 `@Configuration @Profile("fabric")` 类：
- `fabricGateway()` bean — 创建 Gateway 实例（gRPC channel + identity + signer + connect）
- `fabricNetwork()` bean — 从 Gateway 获取 Network
- `carbonContract()` bean — 从 Network 获取 Contract
- Gateway bean `destroyMethod = "close"` — 应用关闭时断开连接
- 从 classpath 资源加载证书和私钥
- gRPC channel 使用 TLS（信任 peer TLS CA 证书）

**Verify:** `mvn compile` 成功；`fabric.enabled=true` + 证书文件存在时 Gateway bean 可创建

### Task 5: 创建 FabricBlockchainService 实现

**Files:**
- `oaiss-chain-backend/src/main/java/com/oaiss/chain/service/FabricBlockchainService.java` (NEW)

`@Service @Profile("fabric")` 实现 `BlockchainServicePort`：
- `commitReportToChain()` → `contract.submitTransaction("CreateCarbonReport", args)` → 解析结果返回 BlockchainResponse
- `commitTradeToChain()` → `contract.submitTransaction("CreateTradeRecord", args)`
- `queryTransaction()` → `contract.evaluateTransaction("GetTransactionByID", txHash)`
- `queryBlock()` → `contract.evaluateTransaction("QueryBlock", blockNumber)`
- `queryReportHistory()` → `contract.evaluateTransaction("QueryReportHistory", reportId)`
- `verifyReportOnChain()` → `contract.evaluateTransaction("VerifyReport", reportId, expectedHash)`
- `checkConnection()` → 返回真实 Fabric 网络状态（connected=true, mode="FABRIC"）
- `listTransactions()` / `listLatestBlocks()` → evaluateTransaction 查询链上数据
- 所有 Fabric 异常映射到 `BlockchainException` 工厂方法

**Verify:** `mvn compile` 成功

## Risk Mitigation

| Risk | Mitigation |
|------|-----------|
| Fabric 容器在 Windows Docker 上性能差 | 使用 named volumes 而非 bind mounts；增加 Docker 内存到 8GB+ |
| gRPC TLS 证书不匹配 | 从 test-network 生成证书后统一复制到 classpath |
| Spring Profile 切换失败 | MockBlockchainService 使用 `@Primary` 作为默认，Fabric 使用 `@Profile("fabric")` |
| 依赖冲突（grpc 版本） | 使用 `grpc-netty-shaded` 避免与 Spring Boot WebFlux grpc 版本冲突 |
