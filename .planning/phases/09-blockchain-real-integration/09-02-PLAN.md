# Plan 09-02: Chaincode 开发 + BlockchainService 真实替换

**Phase:** 9 (区块链真实对接)
**Requirement:** REQ-05 (BlockchainService 从 Mock 升级为 Fabric Gateway SDK)
**Depends on:** Plan 09-01 (Fabric 网络搭建 + Gateway SDK 集成)
**Estimated tasks:** 7

## Goal

开发 Go 链码（carbon-chaincode）实现碳报告和交易记录的链上存储与查询，部署到 Fabric 通道，完成 BlockchainService 从 Mock 到真实 Fabric 调用的替换，确保所有 REST API endpoint 返回真实链上数据。

## Success Criteria

1. Go 链码 `carbon-chaincode` 编译通过，单元测试通过
2. 链码部署到 Fabric `mychannel` 通道，`peer lifecycle chaincode querycommitted` 确认已提交
3. `BlockchainController` 所有 5 个 endpoint 通过 `BlockchainServicePort` 调用真实 Fabric 数据
4. 碳报告审批后的上链流程走真实 Fabric 通道（CarbonService.approveReport → FabricBlockchainService.commitReportToChain）
5. 前端 Blockchain.vue 页面显示真实链上数据（交易哈希、区块号、时间戳）
6. `fabric.enabled=false` 时 Mock 模式仍正常工作（无破坏性变更）
7. 后端编译通过，单元测试通过

## Tasks

### Task 1: 创建 Go 链码项目结构

**Files:**
- `oaiss-chain-chaincode/go.mod` (NEW)
- `oaiss-chain-chaincode/go.sum` (NEW)
- `oaiss-chain-chaincode/chaincode.go` (NEW)

创建 `oaiss-chain-chaincode/` 目录：
- `go.mod` — module `github.com/oaiss/chain/chaincode`, Go 1.21+, 依赖 `fabric-contract-api-go v1.2.2`
- 链码结构体 `CarbonChaincode` 包含以下合约函数：

| Function | Type | Purpose | Args |
|----------|------|---------|------|
| `CreateCarbonReport` | submit | 碳报告上链 | reportId, reportHash, enterpriseId, enterpriseName |
| `QueryReportHistory` | evaluate | 查询报告历史 | reportId |
| `CreateTradeRecord` | submit | 交易记录上链 | tradeId, sellerId, buyerId, amount, price |
| `VerifyReport` | evaluate | 验证报告哈希 | reportId, expectedHash |
| `GetTransactionByID` | evaluate | 查询交易详情 | txId |
| `QueryBlock` | evaluate | 查询区块信息 | blockNumber (string) |
| `GetAllReports` | evaluate | 查询所有报告 | (无参数，返回全部) |

链上数据结构：
- `CarbonReportRecord` — reportId, reportHash, enterpriseId, enterpriseName, txType, timestamp
- `TradeRecord` — tradeId, sellerId, buyerId, amount, price, txType, timestamp
- Key 格式: `REPORT_{reportId}`, `TRADE_{tradeId}`

**Verify:** `go build` 成功

### Task 3: 链码部署脚本

**Files:**
- `scripts/deploy-chaincode.sh` (NEW)

创建部署脚本：
1. 打包链码: `peer lifecycle chaincode package`
2. 安装链码: `peer lifecycle chaincode install`
3. 审批链码: `peer lifecycle chaincode approveformyorg`
4. 提交链码: `peer lifecycle chaincode commit`
5. 验证部署: `peer lifecycle chaincode querycommitted`

脚本使用 Fabric CLI 容器（docker exec）执行命令，避免本地安装 peer CLI。

**Verify:** 链码部署成功，`querycommitted` 返回 carbon-chaincode

### Task 4: 完善 FabricBlockchainService — submitTransaction 实现

**Files:**
- `oaiss-chain-backend/src/main/java/com/oaiss/chain/service/FabricBlockchainService.java` (UPDATE)

完善 commitReportToChain 和 commitTradeToChain：
- 使用 `contract.newProposal("func", args).build().send()` 获取 transactionId
- 使用 `transaction.getCommitted()` 获取 blockNumber
- 解析 chaincode 返回的 JSON 结果
- 构建 BlockchainResponse DTO（txHash, blockNumber, timestamp, channelId, status）
- 异常处理：EndorsementException → BlockchainException.smartContractError, CommitException → BlockchainException.txCommitFailed

**Verify:** `mvn compile` + `mvn test` 通过

### Task 5: 完善 FabricBlockchainService — evaluateTransaction 实现

**Files:**
- `oaiss-chain-backend/src/main/java/com/oaiss/chain/service/FabricBlockchainService.java` (UPDATE)

完善查询方法：
- `queryTransaction()` → evaluateTransaction("GetTransactionByID") → 解析 JSON → BlockchainTransactionResponse
- `queryBlock()` → evaluateTransaction("QueryBlock") → 解析 JSON → BlockchainBlockResponse
- `queryReportHistory()` → evaluateTransaction("QueryReportHistory") → 解析 JSON → List<BlockchainReportHistoryResponse>
- `verifyReportOnChain()` → evaluateTransaction("VerifyReport") → 返回 boolean
- `checkConnection()` → 返回 {connected: true, mode: "FABRIC", channel, peers, orderers}
- `listTransactions()` / `listLatestBlocks()` → evaluateTransaction 查询 → 分页包装

JSON 解析使用 Jackson ObjectMapper（项目已有依赖）。

**Verify:** `mvn test -Dtest=FabricBlockchainServiceTest` 通过

## Risk Mitigation

| Risk | Mitigation |
|------|-----------|
| 链码部署失败（peer 不可达） | 使用 deploy-chaincode.sh 脚本，内含健康检查和重试 |
| submitTransaction 超时（1-3秒共识） | 设置合理超时（30秒），添加日志记录 |
| 链码返回格式与 DTO 不匹配 | 使用 Jackson 解析 JSON，添加字段映射容错 |
| Windows 上 Go 编译问题 | 链码在 Docker 容器内编译（peer lifecycle 使用外部构建） |
