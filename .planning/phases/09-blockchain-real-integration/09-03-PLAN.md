# Plan 09-03: Fabric CA 集成（REQ-12 optional，可降级）

**Phase:** 9 (区块链真实对接)
**Requirement:** REQ-12 (身份认证区块链方案 — Fabric CA 集成, optional)
**Depends on:** Plan 09-01 (Fabric 网络搭建), Plan 09-02 (Chaincode + BlockchainService 替换)
**Estimated tasks:** 5

## Goal

集成 Fabric CA 为用户签发区块链身份证书，实现 JWT 用户与 Fabric 链上身份的映射。REQ-12 标记为 optional，若 Fabric CA 集成困难可降级为 mock CA（使用 test-network 预生成的静态证书）。

## Success Criteria

1. Fabric CA 服务 (`ca.org1.example.com`) 在 Docker 中运行并可响应 enrollment 请求
2. `FabricCaService` 可通过 Fabric CA SDK 注册和登记用户，获取 X.509 证书和私钥
3. 企业用户首次触发区块链操作时，系统自动为其创建 Fabric 身份（或使用共享组织身份）
4. MVP 降级方案：使用 test-network 预生成的 `User1@org1.example.com` 静态证书作为共享身份
5. 后端编译通过，单元测试通过

## Tasks

### Task 1: 添加 Fabric CA SDK Maven 依赖

**Files:** `oaiss-chain-backend/pom.xml` (UPDATE)

添加依赖：
- `org.hyperledger.fabric-ca-sdk:fabric-ca-sdk:1.5.8` — Fabric CA 客户端

**Verify:** `mvn compile` 成功，无依赖冲突

### Task 2: 创建 FabricCaService（可选实现）

**Files:**
- `oaiss-chain-backend/src/main/java/com/oaiss/chain/service/FabricCaService.java` (NEW)
- `oaiss-chain-backend/src/main/java/com/oaiss/chain/config/FabricCaConfig.java` (NEW)

`FabricCaService` 提供：
- `enrollUser(userId, secret)` — 使用 Fabric CA 登记用户，返回 X.509 证书和私钥
- `registerUser(userId, role, affiliation)` — 注册新用户到 Fabric CA
- `getOrCreateIdentity(userId)` — 检查 Redis 缓存是否有用户 Fabric 身份，若无则注册+登记

`FabricCaConfig`：
- `@Profile("fabric-ca")` — 仅在启用 Fabric CA 时激活
- 创建 `FabricCAClient` bean，连接到 `ca.org1.example.com:7054`
- 使用 admin 身份（admin/adminpw from test-network）作为登记管理员

**Verify:** `mvn compile` 成功

### Task 3: JWT-to-Fabric 身份映射策略实现

**Files:**
- `oaiss-chain-backend/src/main/java/com/oaiss/chain/service/FabricIdentityService.java` (NEW)

身份映射策略（MVP 简化版）：
1. **共享组织身份模式**（默认）— 所有区块链操作使用 `User1@org1.example.com` 的预生成证书
2. **按用户身份模式**（fabric-ca profile）— 每个企业用户有自己的 Fabric 身份

`FabricIdentityService`：
- `@Profile("fabric")` — 共享身份模式
- `@Profile("fabric-ca")` — 按用户身份模式
- 共享模式：直接使用 FabricGatewayConfig 中配置的 Gateway identity
- 按用户模式：从 Redis 缓存获取用户证书，动态创建 Gateway 连接

**Verify:** `mvn compile` 成功

### Task 5: 降级方案确认 + 文档更新

**Files:**
- `.planning/STATE.md` (UPDATE)
- `oaiss-chain-backend/src/main/resources/application.yml` (UPDATE)

确认降级方案：
- `fabric.enabled=true` + `fabric-ca.enabled=false` → 使用共享组织身份（MVP 默认）

```yaml
    endpoint: http://ca.org1.example.com:7054
    admin-name: admin
    admin-password: adminpw
```

STATE.md 更新：
- REQ-12 状态标记为 "MVP: 共享组织身份 (mock CA fallback)"
- Fabric CA 集成标记为 "降级方案可用"

**Verify:** 配置正确，Mock 和 Fabric profile 都能正常启动

## Risk Mitigation

| Risk | Mitigation |
|------|-----------|
| Fabric CA enrollment 失败 | MVP 使用共享组织身份，不依赖 Fabric CA |
| 证书缓存丢失（Redis） | 重新登记即可，不影响链上数据 |
| Fabric CA SDK 与 Gateway SDK 版本冲突 | 两个 SDK 是独立包，无冲突风险 |
| Windows 上 Fabric CA 容器不稳定 | CA 容器仅在 fabric-ca profile 时需要，默认不依赖 |
