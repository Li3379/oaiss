# Plan 05-05: Admin Management Test Script

**Phase:** 5 — Supporting Domains
**Script:** `scripts/admin-test.sh`
**Requirements:** ADMIN-01, ADMIN-02, ADMIN-03, ADMIN-04, ADMIN-05
**Role:** ADMIN
**Status:** Pending

## Goal

Verify admin user management (list, status toggle, dashboard, statistics) via `AdminController` endpoints. ADMIN-02 (create user) and ADMIN-03 (edit user) are recorded as code gaps — no backend endpoints exist.

## Success Criteria

1. `GET /admin/users` returns 200 with paginated user list (ADMIN-01)
2. `GET /admin/users?userType=1` filters by enterprise type
3. `PUT /admin/users/{userId}/status?status=0` disables a user — returns 200 (ADMIN-04)
4. `PUT /admin/users/{userId}/status?status=1` re-enables the user — returns 200
5. `GET /admin/dashboard` returns 200 with totalUsers field (ADMIN-05)
6. `GET /admin/statistics` returns 200 with enterpriseCount, reviewerCount, thirdPartyCount (ADMIN-05)
7. ADMIN-02 and ADMIN-03 documented as known code gaps in test output

## Approach

Single bash script:
- Login as admin
- Test all 4 existing endpoints
- Test status toggle on a non-admin user (enterprise001)
- Document ADMIN-02/03 gaps in output
- Verify dashboard and statistics return expected fields

## Implementation Steps

1. Create `scripts/admin-test.sh` with boilerplate
2. Login as admin, extract token
3. **ADMIN-01:** `GET /admin/users?page=1&size=10` — assert 200, assert `content` array present
4. `GET /admin/users?userType=1&page=1&size=10` — assert 200, verify filtered results
5. Get enterprise001's userId from user list
6. **ADMIN-04:** `PUT /admin/users/{userId}/status?status=0` — assert 200 (disable)
7. Verify disabled: `GET /admin/users?status=0` — assert enterprise001 in results
8. Re-enable: `PUT /admin/users/{userId}/status?status=1` — assert 200
9. **ADMIN-05:** `GET /admin/dashboard` — assert 200, assert `totalUsers` field
10. `GET /admin/statistics` — assert 200, assert `enterpriseCount`, `reviewerCount`, `thirdPartyCount`
11. Print gap notice: "ADMIN-02 (create user): CODE GAP — no backend endpoint"
12. Print gap notice: "ADMIN-03 (edit user): CODE GAP — no backend endpoint"
13. Summary with pass/fail counts
