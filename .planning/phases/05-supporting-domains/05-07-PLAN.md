# Plan 05-07: Cross-Entity Search Test Script

**Phase:** 5 — Supporting Domains
**Script:** `scripts/search-test.sh`
**Requirements:** SRCH-01
**Role:** Any authenticated (use enterprise001)
**Status:** Pending

## Goal

Verify cross-entity search returns correct results across enterprises via `SearchController` endpoints: report search, trade search, and market overview.

## Success Criteria

1. `GET /search/reports` returns 200 with report search results
2. `GET /search/reports?keyword=test` filters by keyword
3. `GET /search/reports?enterpriseId=1` filters by enterprise
4. `GET /search/trades` returns 200 with trade search results
5. `GET /search/market-overview` returns 200 with market statistics
6. Cross-entity search works (admin can see all enterprises' data)

## Approach

Single bash script:
- Login as enterprise001 (any authenticated role works)
- Test all 3 search endpoints
- Search tests run LAST in Phase 5 sequence (D-02) to leverage accumulated test data from Phases 2-4
- Verify pagination works

## Implementation Steps

1. Create `scripts/search-test.sh` with boilerplate
2. Login as enterprise001, extract token
3. **SRCH-01:** `GET /search/reports?page=1&size=10` — assert 200, assert content array
4. `GET /search/reports?keyword=报告&page=1&size=10` — assert 200 (keyword filter)
5. `GET /search/reports?status=2&page=1&size=10` — assert 200 (status filter)
6. `GET /search/trades?page=1&size=10` — assert 200, assert content array
7. `GET /search/trades?tradeType=1&page=1&size=10` — assert 200 (type filter)
8. `GET /search/market-overview` — assert 200, assert market data fields
9. Login as admin, verify cross-entity search works
10. `GET /search/reports?page=1&size=10` as admin — assert 200 (sees all enterprises)
11. Summary with pass/fail counts

## Risk Mitigation

- **Empty results:** If Phases 2-4 data doesn't exist, search returns empty — still valid (200 + empty content)
- **Run last:** Search tests should execute after all other Phase 5 scripts (D-02) to maximize data availability
- **Pagination:** Backend uses `page` (1-indexed) not `pageNum` — verify correct param name
