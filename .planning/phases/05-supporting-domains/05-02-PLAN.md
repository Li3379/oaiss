# Plan 05-02: File Management Test Script

**Phase:** 5 — Supporting Domains
**Script:** `scripts/file-test.sh`
**Requirements:** FILE-01, FILE-02, FILE-03
**Role:** Any authenticated (use enterprise001)
**Status:** Pending

## Goal

Verify file upload to MinIO, download, file info, and MinIO console accessibility work end-to-end via `FileController` endpoints.

## Success Criteria

1. `POST /file/upload` with multipart file returns 200 with objectName field
2. `GET /file/info` returns file metadata (size, contentType)
3. `GET /file/download` returns file content (verify via HTTP status 200)
4. `GET /file/exists` returns true for uploaded file
5. `GET /file/list` returns uploaded files in listing
6. `GET /file/presigned-url` returns a valid URL string
7. `DELETE /file` removes the file successfully
8. MinIO console at `localhost:9001` is accessible (HTTP 200)

## Approach

Single bash script:
- Login as enterprise001
- Create a small temp file for upload
- Full lifecycle: upload → info → exists → list → presigned-url → download → delete → verify deleted
- Separate check: MinIO console accessibility

## Implementation Steps

1. Create `scripts/file-test.sh` with boilerplate
2. Login as enterprise001, extract token
3. Create temp test file: `echo "test content" > /tmp/oaiss-test-file.txt`
4. **FILE-01:** `POST /file/upload` with multipart — assert 200, extract objectName
5. `GET /file/info?objectName=...` — assert 200, assert size/contentType fields
6. `GET /file/exists?objectName=...` — assert `{data: true}`
7. `GET /file/list?prefix=...` — assert 200, assert uploaded file in results
8. `GET /file/presigned-url?objectName=...` — assert 200, assert URL starts with http
9. **FILE-02:** `GET /file/download?objectName=...` — assert HTTP 200
10. `DELETE /file?objectName=...` — assert 200
11. Verify deleted: `GET /file/exists?objectName=...` — assert `{data: false}`
12. **FILE-03:** `curl -sf http://localhost:9001` — assert accessible (MinIO console)
13. Cleanup: remove temp file
14. Summary with pass/fail counts

## Key Endpoints

| Endpoint | Method | Role | Purpose |
|----------|--------|------|---------|
| `/file/upload` | POST | Any authenticated | Upload file (multipart) |
| `/file/info` | GET | Any authenticated | File metadata |
| `/file/exists` | GET | Any authenticated | Check existence |
| `/file/download` | GET | Any authenticated | Download file |
| `/file/list` | GET | Any authenticated | List files |
| `/file/presigned-url` | GET | Any authenticated | Get presigned URL |
| `/file/delete` | DELETE | Owner/Admin | Delete file |

## Risk Mitigation

- **MinIO not running:** Script checks MinIO early; fails fast if unavailable
- **File upload from bash:** Use `curl -F "file=@/tmp/test.txt"` for multipart
- **Cleanup:** Always delete uploaded files in test, even on failure (trap handler)

## Verification

Run `bash scripts/file-test.sh` — all tests should pass with 0 failures.
