# Plan 05-04: Blockchain Explorer Test Script

**Phase:** 5 — Supporting Domains
**Script:** `scripts/blockchain-test.sh`
**Requirements:** BLOCK-01, BLOCK-02, BLOCK-03
**Role:** ADMIN (covers all @PreAuthorize combinations)
**Status:** Pending

## Goal

Verify blockchain explorer mock mode works: connection status, block listing, block detail, transaction listing, and transaction detail all return structurally correct mock data.

## Success Criteria

1. `GET /blockchain/status` returns 200 with `connected:true`, `channel:"carbon-channel"`, `mode:"MOCK"`
2. `GET /blockchain/blocks/latest` returns 200 with block list; each block has `blockNumber` (positive int), `blockHash` (starts with `0x`)
3. `GET /blockchain/block/{blockNumber}` returns 200 with block detail
4. `GET /blockchain/transactions` returns 200 with transaction list
5. `GET /blockchain/transaction/{txHash}` returns 200 with transaction detail; `txHash` starts with `tx_mock_`
6. All mock transactions have `status:"VALID"`
7. Pagination works (page/size params accepted)

## Approach

Single bash script:
- Login as admin
- Test all 5 blockchain endpoints
- Assert STRUCTURE only (mock data is random each call — do not assert specific values)
- Format validation per D-08 rules

## Implementation Steps

1. Create `scripts/blockchain-test.sh` with boilerplate
2. Login as admin, extract token
3. **BLOCK-01:** `GET /blockchain/status` — assert 200, assert `connected`, `channel`, `mode` fields
4. **BLOCK-02:** `GET /blockchain/blocks/latest?page=1&size=5` — assert 200, extract first blockNumber and blockHash
5. Validate blockHash starts with `0x`
6. Validate blockNumber is positive integer
7. `GET /blockchain/block/{blockNumber}` — assert 200, assert block detail fields
8. **BLOCK-03:** `GET /blockchain/transactions?page=1&size=5` — assert 200, extract first txHash
9. Validate txHash starts with `tx_mock_`
10. `GET /blockchain/transaction/{txHash}` — assert 200, assert `status` field present
11. Validate status is `VALID`
12. Test pagination: `GET /blockchain/blocks/latest?page=2&size=5` — assert 200
13. Summary with pass/fail counts

## Risk Mitigation

- **Random mock data:** Assert structure/format only, never specific values
- **txHash format:** Must start with `tx_mock_` (not hex) — per BlockchainService source
- **blockHash format:** Must start with `0x` — per UUID-based generation in BlockchainService
- **Empty results unlikely:** Mock generates data on-the-fly, always returns results
