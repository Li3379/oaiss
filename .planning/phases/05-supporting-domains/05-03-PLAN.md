# Plan 05-03: Emission Ratings Test Script

**Phase:** 5 — Supporting Domains
**Script:** `scripts/emission-test.sh`
**Requirements:** EMIT-01, EMIT-02, EMIT-03
**Role:** ADMIN (covers all endpoints)
**Status:** Pending

## Goal

Verify emission data viewing, emission rating creation/recalculation, industry rankings, and AI prediction work via `EmissionController` endpoints.

## Success Criteria

1. `GET /emission/ratings/{enterpriseId}` returns 200 with rating list
2. `POST /emission/ratings` creates/recalculates a rating — returns 200 with rating data
3. `GET /emission/rankings/{year}` returns 200 with ranking list
4. `POST /emission/predict` returns 200 with prediction data
5. Emission factors are loaded (hardcoded in CachePreloadService) — verified indirectly through rating calculation

## Approach

Single bash script:
- Login as admin (ADMIN role covers all emission endpoints)
- Check existing data first (Phase 2 approvals may have created ratings)
- Create rating if none exists, then verify all read endpoints
- Test prediction endpoint with sample data

## Implementation Steps

1. Create `scripts/emission-test.sh` with boilerplate
2. Login as admin, extract token
3. Get enterprise001's userId (from auth/me or known from seed data)
4. **EMIT-01:** `GET /emission/ratings/{enterpriseId}` — assert 200, check if ratings exist
5. If no ratings exist: `POST /emission/ratings` with enterpriseId, year, totalEmission, revenue, ratedBy — assert 200
6. **EMIT-02:** `GET /emission/rankings/2025` — assert 200, assert list returned
7. **EMIT-03:** `POST /emission/predict` with sample request — assert 200, assert prediction fields present
8. DB verification: query `emission_rating` table for enterprise001's data
9. Summary with pass/fail counts

## Key Endpoints

| Endpoint | Method | Role | Purpose |
|----------|--------|------|---------|
| `/emission/ratings/{enterpriseId}` | GET | Any authenticated | View enterprise rating history |
| `/emission/ratings` | POST | Any authenticated | Create/recalculate rating |
| `/emission/rankings/{year}` | GET | Any authenticated | Industry ranking |
| `/emission/predict` | POST | Any authenticated | AI carbon prediction |

## Risk Mitigation

- **No existing ratings:** Create one via POST /ratings before testing read endpoints
- **Prediction model:** May require specific input format — check CarbonPredictionRequest DTO
- **Hardcoded factors:** Accept current values; do not test factor changes (D-15)

## Verification

Run `bash scripts/emission-test.sh` — all tests should pass with 0 failures.
