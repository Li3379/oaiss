<objective>
Fix the dev profile to use Flyway migrations instead of Hibernate ddl-auto:update, ensuring schema consistency across all environments.

Purpose: The dev profile currently bypasses Flyway and uses Hibernate's ddl-auto:update for schema management. This causes schema drift — developers see a different schema than what production uses. Flyway migrations are also untested during local development.
Output: Updated application-dev.yml with ddl-auto: validate and flyway.enabled: true.
</objective>
