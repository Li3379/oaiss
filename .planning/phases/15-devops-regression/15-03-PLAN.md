E2E test categories:
- smoke/ (4 files): Basic login and page load for each role
- flows/ (12 files): Full business flow tests (auth, carbon report, auction, trade, etc.)

<task type="manual">
  <name>Task 1: Prepare test environment</name>
  <action>
    Ensure the full stack is running with a clean database:

    1. Start infrastructure: `docker-compose up mysql redis minio -d`
    2. Verify services are healthy:
       - MySQL: `docker exec oaiss-mysql mysqladmin ping -h localhost`
       - Redis: `docker exec oaiss-redis redis-cli -a <password> ping`
       - MinIO: `curl http://localhost:9002/minio/health/live`
    3. Start backend with dev profile (after 15-01 fix): `cd oaiss-chain-backend && mvn spring-boot:run -Dspring-boot.run.profiles=dev`
    4. Wait for backend health: `curl http://localhost:8080/api/v1/actuator/health`
    5. Start frontend: `cd oaiss-chain-frontend && npm run dev`
    6. Verify frontend: `curl http://localhost:5173`

    Note: If the database already has data from previous test runs, consider resetting it to get clean seed data from V2 migration.
  </action>
  <verify>
    Backend health endpoint returns {"status":"UP"}. Frontend loads at localhost:5173.
  </verify>
  <done>Full stack running: MySQL + Redis + MinIO + Backend + Frontend. All health checks passing.</done>

<task type="manual">
  <name>Task 5: Analyze failures and create regression report</name>
  <action>
    Analyze all test failures:

    1. Categorize failures:
       - **Infrastructure**: Service not running, connectivity issues
       - **v2.0 Regression**: Caused by Phase 13-14 changes (auth, permissions, schema, etc.)
       - **Pre-existing**: Existed before v2.0 changes
       - **Test bug**: Test code issue, not application bug

    2. For each v2.0 regression failure:
       - Identify which Phase 13-14 change caused it
       - Determine if the failure indicates a real bug or expected behavior change
       - Recommend fix (application code or test update)

    3. Calculate overall pass rate:
       - Total tests / (Total - Skipped)
       - Target: >90% pass rate

    4. Write results to 15-03-SUMMARY.md with:
       - Per-category results table
       - Failure analysis
       - Recommendations
       - Overall verdict (PASS/FAIL)
  </action>

  </verify>
