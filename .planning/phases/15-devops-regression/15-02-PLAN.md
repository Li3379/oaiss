<task type="auto">
  <name>Task 1: Fix backend CI/CD pipeline — remove broken OWASP job, fix deploy logic (OPS-01)</name>
  <files>oaiss-chain-backend/.github/workflows/ci-cd.yml</files>
  <action>
    Fix `ci-cd.yml` with these changes:

    1. **Remove or replace the `security` job**: The OWASP dependency-check-maven plugin is NOT configured in pom.xml. Either:
       - Option A (recommended): Replace with a lightweight Trivy filesystem scan that doesn't require Maven plugin
       - Option B: Add a note that OWASP scan requires plugin setup in pom.xml first
       Choose Option A: Replace the `security` job with a Trivy scan that scans the compiled JAR.

    2. **Fix deploy-staging logic**: The `docker-build` job has condition `github.event_name == 'push' && github.ref == 'refs/heads/main'`, but `deploy-staging` checks `github.ref == 'refs/heads/develop'`. Since deploy-staging depends on docker-build, and docker-build only runs on main, deploy-staging can NEVER execute. Fix: Change docker-build to also run on develop pushes, OR remove deploy-staging (it's a placeholder anyway).

       Recommended fix: Make docker-build run on both main and develop:
       ```yaml
       docker-build:
         if: github.event_name == 'push' && (github.ref == 'refs/heads/main' || github.ref == 'refs/heads/develop')
       ```

    3. **Keep deploy steps as-is (placeholder)**: They are intentionally placeholder — real deployment will be added when infrastructure is ready. No change needed.

    4. **Remove Slack notification dependency on docker-build**: The `notify` job depends on `[build, docker-build]` but docker-build only runs on push to main. This means notify is skipped on PRs even if build fails. Fix: Change notify to depend only on `build` for PR scenarios.
  </action>
  <verify>
    <automated>cd oaiss-chain-backend && cat .github/workflows/ci-cd.yml | grep -c "dependency-check-maven" && echo "--- OWASP ref count (should be 0) ---" && grep "refs/heads/develop" .github/workflows/ci-cd.yml && echo "--- deploy staging trigger ---"</automated>
  </verify>
  <done>CI/CD pipeline fixed: OWASP replaced with Trivy, deploy-staging logic consistent, notification job works on all events.</done>
