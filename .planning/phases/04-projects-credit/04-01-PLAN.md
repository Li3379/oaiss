# Plan 04-01: Carbon Neutral Project CRUD + Status Transitions + Role Gap Investigation

**Status**: PENDING
**Wave**: 1 (independent)
**Requirements**: PROJ-01, PROJ-02, PROJ-03, PROJ-04, PROJ-05
**Estimated Duration**: 15-20 minutes

## Goal

Verify the full carbon neutral project lifecycle: create, list, detail, submit, approve/reject, start implementation, terminate. Document the VERIFIER/CERTIFIER role gap with evidence.

## Requirements Coverage

| Req | Description | Test Method |
|-----|-------------|-------------|
| PROJ-01 | Create project + view list + view detail | API: POST /carbon-neutral, GET /my, GET /{id} |
| PROJ-02 | Submit for review (DRAFT→PENDING) | API: POST /{id}/submit |
| PROJ-03 | Review: approve and reject (PENDING→APPROVED/REJECTED) | API: POST /{id}/review as ADMIN |
| PROJ-04 | Start implementation + terminate (APPROVED→IMPLEMENTING→TERMINATED) | API: POST /{id}/start, POST /{id}/terminate |
| PROJ-05 | VERIFIER/CERTIFIER role gap investigation | Attempt /verify and /certify as AUTHENTICATOR; document 403; execute as ADMIN fallback |

## Implementation Steps

### Step 1: Create test script `scripts/project-lifecycle-test.sh`

**Authentication** (reuse pattern from Phase 3):
```bash
# Login enterprise001, reviewer001, admin, authenticator001
# All via POST /api/v1/auth/login with password admin123
# Extract token from response.data.accessToken
```

**Test PROJ-01: Project CRUD**
```
1. POST /api/v1/carbon-neutral (as enterprise001)
   Body: { projectName, projectType:1, description, location, expectedReduction:5000 }
   Assert: code=200, data.id present, data.status=0 (DRAFT)

2. GET /api/v1/carbon-neutral/my (as enterprise001)
   Assert: code=200, data.content contains created project

3. GET /api/v1/carbon-neutral/{id} (as enterprise001)
   Assert: code=200, data.status=0, data.projectName matches
```

**Test PROJ-02: Submit for review**
```
4. POST /api/v1/carbon-neutral/{id}/submit (as enterprise001)
   Assert: code=200, data.status=1 (PENDING)
```

**Test PROJ-03: Review (approve + reject)**
```
5. Create second project for rejection:
   POST /api/v1/carbon-neutral (as enterprise001) → project B
   POST /api/v1/carbon-neutral/{idB}/submit (as enterprise001)

6. POST /api/v1/carbon-neutral/{idA}/review (as admin)
   Body: { "approved": true, "comment": "Approved for testing" }
   Assert: code=200, data.status=2 (APPROVED)

7. POST /api/v1/carbon-neutral/{idB}/review (as admin)
   Body: { "approved": false, "comment": "Insufficient documentation" }
   Assert: code=200, data.status=6 (REJECTED)
```

**Test PROJ-04: Start + Terminate**
```
8. POST /api/v1/carbon-neutral/{idA}/start (as enterprise001)
   Assert: code=200, data.status=3 (IMPLEMENTING)

9. POST /api/v1/carbon-neutral/{idA}/terminate (as enterprise001)
   Body: { "reason": "Testing termination" }
   Assert: code=200, data.status=5 (TERMINATED)
```

**Test PROJ-05: Role gap investigation**
```
10. Create new project C, submit, approve, start implementation:
    POST /carbon-neutral → status=0
    POST /{idC}/submit → status=1
    POST /{idC}/review (admin, approved:true) → status=2
    POST /{idC}/start → status=3

11. POST /carbon-neutral/{idC}/submit-verification (as enterprise001)
    Body: { "verifierId": <authenticator001_user_id> }
    Assert: code=200, data.verificationStatus=1 (PENDING)

12. POST /carbon-neutral/verify (as AUTHENTICATOR token)
    Body: { "projectId": idC, "verifiedReduction": 3000 }
    Assert: code=403 (VERIFIER role not in UserTypeEnum)
    LOG: "VERIFIER role gap: @PreAuthorize requires hasRole('VERIFIER') but UserTypeEnum has AUTHENTICATOR(5)"

13. POST /carbon-neutral/verify (as ADMIN token)
    Body: { "projectId": idC, "verifiedReduction": 3000, "verificationReport": "..." }
    Assert: code=200, data.verificationStatus=2 (VERIFIED), data.issuedCredits=3000
    LOG: "ADMIN workaround succeeds for verification"

14. POST /carbon-neutral/{idC}/apply-certification (as enterprise001)
    Body: { "certOrg": "TestCertOrg" }
    Assert: code=200, data.certStatus=1 (PENDING)

15. POST /carbon-neutral/{idC}/certify (as AUTHENTICATOR token)
    Body: { "certNo": "CERT-001" }
    Assert: code=403 (CERTIFIER role not in UserTypeEnum)
    LOG: "CERTIFIER role gap: @PreAuthorize requires hasRole('CERTIFIER') but UserTypeEnum has AUTHENTICATOR(5)"

16. POST /carbon-neutral/{idC}/certify (as ADMIN token)
    Body: { "certNo": "CERT-001" }
    Assert: code=200, data.certStatus=2 (CERTIFIED), data.certNo=CERT-001
    LOG: "ADMIN workaround succeeds for certification"
```

### Step 2: Run and verify

```bash
chmod +x scripts/project-lifecycle-test.sh
bash scripts/project-lifecycle-test.sh
```

Expected: 16 test assertions, all PASS (403s are expected/valid for role gap tests).
