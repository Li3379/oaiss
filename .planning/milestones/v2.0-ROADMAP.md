## Phases

### Phase 13: 并发安全与凭据加固

**Goal**: 消除金融交易竞态风险，外部化所有硬编码凭据，补全授权注解
**Depends on**: Phase 12 (v1.1.0 shipped)
**Requirements**: CON-01~03, SEC-07~13
**Plans**: 3 plans

Plans:

- [x] 13-01: @DistributedLock + @Version optimistic lock + lock-before-transaction (CON-01, CON-02, CON-03)
- [x] 13-02: Externalize docker-compose & YAML credentials, remove insecure defaults (SEC-07, SEC-08, SEC-09)
- [x] 13-03: @PreAuthorize on controllers, remove X-User-Id fallback, Prometheus auth (SEC-10, SEC-11, SEC-12, SEC-13)

**Key Changes:**
- DoubleAuctionService: `synchronized` → `@DistributedLock` (Redis-based cross-JVM mutex)
- Enterprise, CarbonCoinAccount, AuctionOrder: `@Version Long version` + Flyway V5
- DistributedLockAspect: `@Order(Ordered.HIGHEST_PRECEDENCE)` ensures lock-before-transaction
- docker-compose.yml/infra.yml: all passwords use `${VAR}` with no fallback defaults
- SecurityStartupValidator: blocks startup on missing/weak credentials (includes MinIO)
- FileController: class-level `isAuthenticated()`, method-level role overrides
- SearchController: `@PreAuthorize("isAuthenticated()")`
- SecurityConfig: `/actuator/prometheus` requires ADMIN, `/actuator/health` permitAll
- JwtAuthenticationFilter: whitelist narrowed to `/actuator/health` only

### Phase 14: 性能优化与代码质量

**Goal**: 解决性能瓶颈，补全事务注解和软删除过滤，加密 RSA 私钥
**Depends on**: Phase 13
**Requirements**: PERF-02~05, SEC-01~02, QUAL-01~02
**Plans**: 2 plans

Plans:

- [x] 14-01: Redis SCAN, @Async cache preload, V6 FK indexes (PERF-02, PERF-03, PERF-04, PERF-05)
- [x] 14-02: AES-256-GCM RSA key encryption, CSRF ADR, readOnly=true, AndDeletedFalse (SEC-01, SEC-02, QUAL-01, QUAL-02)

**Key Changes:**
- CachePreloadService: `redisTemplate.keys()` → `ScanOptions` + `redisTemplate.scan()`
- AsyncConfig + `@Async` on cache preload (non-blocking startup)
- Flyway V6: 11 FK indexes across carbon_report, trade, auction_order, etc.
- AesGcmEncryptor: AES-256-GCM envelope encryption for RSA private keys
- RsaKeyMigrationRunner: encrypts existing plaintext keys on startup
- Flyway V7: adds `encrypted` column to `rsa_key_pair`
- ADR-001: documents CSRF disabling rationale for JWT+sessionStorage architecture
- 25 read-only `@Transactional` methods annotated with `readOnly=true`
- 6 repository queries updated with `AndDeletedFalse` (soft-delete filtering)
